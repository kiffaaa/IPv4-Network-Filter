# Правила выполнения задания с использоанием Git
После получения задания склонируйте свой репозиторий на компьютер и настройте _локальный_ репозиторий:
Укажите ваши имя и фамилию, а также университетский адрес электронной почты (_логин@edu.rea.ru_)

`git config --local user.name = "<Имя> <Фамилия>"`

`git config --local user.email = <login>@edu.rea.ru`

> [!IMPORTANT]
> Не используйте глобальные и системные уровни настроек при работе на публичных (университетских) компьютерах! 

Для начала работы создайте ветку с вашим логином студенческой учётной записи `git checkout -b <login>`

Поочерёдно выполняйте задачи/этапы из полученного задания. Коммиты *должны* отображать реальный процесс работы над кодом - старайтесь делать коммит не реже, чем после реализации каждого пунтка/задачи. В этом случае в сообщении к комиту следует указывать соответствующий пункт задания.
`git commit -m "Выполнен п.3-а"`

При правках в описании коммитов указывайте не факт, а суть правок.

Не забудьте отправить измнения на сервер с помощью `git push`.

Когда будете готовы, создайте запрос на слияние.
